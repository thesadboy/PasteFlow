Features & Highlights

专为 macOS 打磨的每一处细节

告别臃肿的 Electron，拥抱真正轻巧、瞬时响应的纯原生剪贴体验。

原生文件全流转 (Finder Native)

不仅能复制文本与图片，PasteFlow 深度集成 macOS 文件描述符。自动感知 Finder 复制的文件与文件夹，动态提取系统原生文件类型图标（PDF、DMG、ZIP 等），粘贴时可直接回填至 Finder、桌面、微信或终端，告别单纯路径文本的尴尬。

真实文件对象 原生图标渲染 多文件打包

零焦点干扰架构

采用底层 nonactivatingPanel 悬浮设计。无论你在哪款应用敲击，呼出 PasteFlow 都绝不会夺走当前编辑器的光标与窗口焦点，选定后毫秒级还原。

全键盘盲打设计

双手无需离开键盘：⌘ 1 ~ ⌘ 9 极速粘贴前九项；按 ↩ 即时送达；⇧ ↩ 智能滤除样式、纯文本安全直出。

多维语义自动识别

自动探测复制内容的类型：十六进制 Hex 色值直接生成预览色块；代码片段语法关键字侦测；URL 链接快速直达，清晰一目了然。

纯本地与绝对隐私

不含任何数据统计 SDK、零网络请求、无需注册登录。所有数据存储于本地 Application Support，并提供多档自动清理保留期。

Efficiency Cheatsheet

行云流水的快捷键

专为键盘极客优化，所有按键均经过严苛的人机工学调试。

⌘ ⇧ V
唤出 / 隐藏面板（支持在偏好设置中一键自定义）
↩ Return
直接粘贴（自动激活目标 App 并注入粘贴事件）
⇧ ↩ Return
以纯文本粘贴（自动去除富文本格式与杂乱样式）
⌘ 1 ~ 9
瞬发粘贴前 9 项（直观数字标记，无需移动光标）
← / →
左右浏览卡片（平滑滚动并自动对齐）
⌫ Delete
删除选中卡片（仅在卡片浏览态有效，智能避开搜索文字删除）
⌘ ,
打开偏好设置（历史时长、热键绑定、音效控制）
Esc
关闭浮层面板

macOS 的安全机制要求模拟键盘事件（例如自动在其他应用程序中注入 ⌘ V 进行真实粘贴）必须获取系统辅助功能（Accessibility）授权。PasteFlow 绝不会利用该权限监听任何敏感输入或密码。
