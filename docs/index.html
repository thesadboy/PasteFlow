Architecture & Highlights

专为 macOS 打磨的每一处细节

告别臃肿的 Web 包装框架，回归瞬时响应的原生应用质感。

原生 Finder 文件对象流转

不仅仅处理文字与链接，PasteFlow 深度支持 macOS 剪贴板文件描述符。复制 Finder 文件后，自动提取系统原生文件类型图标，粘贴时无缝回填至 Finder 文件夹、桌面、微信或终端，而非单纯的路径文本。

文件对象流转 系统原生图标 多文件打包

不夺取焦点架构

基于底层的 nonactivatingPanel 悬浮设计。无论正在哪款编辑器输入，唤出 PasteFlow 均绝不抢占当前窗口焦点，选中后毫秒级还原。

全键盘盲打交互

双手无需离开键位：⌘ 1 ~ ⌘ 9 极速粘贴对应序号卡片；按 ↩ 瞬发送达；⇧ ↩ 自动剥离杂乱格式、纯文本安全直出。

智能内容类型识别

自动识别 Hex 十六进制色值并渲染调色预览；代码片段关键字侦测与等宽渲染；Web URL 智能折叠直达，清晰一目了然。

纯本地与绝对隐私

不含任何数据统计 SDK，零网络遥测，无需注册登录。所有数据保存在本地 Application Support，支持自定义保留天数与敏感数据清理。

Keyboard Efficiency

行云流水的快捷键

专为人机工学优化，支持在偏好设置中自由绑定习惯按键。

⌘ ,

这是 macOS 对未通过苹果年费开发者计划签名的开源应用施加的安全隔离。

解除方法一（终端命令）：
xattr -cr /Applications/PasteFlow.app

解除方法二： 打开访达「应用程序」目录，按住 Control 键点击 PasteFlow 选择「打开」，在提示窗口点击「仍要打开」即可。
macOS 安全架构要求任何自动模拟按键（将选中的历史记录注入到目标软件中进行自动粘贴）必须获得辅助功能（Accessibility）授权。PasteFlow 绝不会利用该权限监听任何敏感输入或密码。

全面原生支持。PasteFlow 采用原生 Swift 构建，完美适配 Apple Silicon (M1/M2/M3/M4 系列) 以及传统 Intel 处理器，无额外运行时开销，内存占用仅 30MB 左右。
